# Portafolio - Jose Manuel Ulloa Hernandez

Bienvenido al repositorio de mi portafolio personal. Este sitio web interactivo ha sido diseñado y desarrollado para mostrar mi experiencia y mis proyectos como Ingeniero en Informática, con un enfoque principal en **Data Engineering**, **Agentes de Inteligencia Artificial** y **Automatización**.

El portafolio se caracteriza por un diseño responsivo, estético y dinámico, apoyado por visualizaciones y animaciones 3D.

---

## 🛠️ Tecnologías utilizadas

El proyecto está construido utilizando un conjunto de herramientas modernas y ligeras:

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Animaciones 3D:** [Three.js](https://threejs.org/)
- **Entorno de desarrollo y empaquetado:** [Vite](https://vitejs.dev/)
- **Despliegue:** Preparado para Vercel o GitHub Pages

## 🚀 Cómo ejecutarlo localmente

Sigue estos pasos para clonar y ejecutar el portafolio en tu entorno de desarrollo local:

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/Yasbenet-dev/Portafolio.git
   cd Portafolio
   ```

2. **Instala las dependencias:**
   ```bash
   npm install
   ```

3. **Inicia el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Visualiza la aplicación:**
   Abre tu navegador web y dirígete a `http://localhost:5173/` (o el puerto que te indique la consola).

## 📂 Proyectos destacados

En este portafolio destaco los siguientes desarrollos, que abarcan el procesamiento de datos y la creación de agentes de IA:

1. **Centralización “After Sales”**
   - Pipeline de ETL completo: desde Web Scraping con autenticación hasta actualización automática en dashboards.
   - *Tech:* Python, SharePoint, Power Automate, Power BI.
2. **Agente de IA para agenda y administración**
   - Agente local orquestado para gestión y reservas automatizadas de un restaurante.
   - *Tech:* Ollama, n8n, Supabase (PostgreSQL), Vercel.
3. **La Metalera: plataforma de gestión**
   - Plataforma para cálculo automático de horas trabajadas y dashboards de analíticas de control de asistencia.
   - *Tech:* React, Vite, PostgreSQL.
